# Garena-Hackathon

We would like to build CrowdPlay, an AI-powered audience director that turns livestreams from something viewers watch into an experience they collectively play.

Today, livestream interaction is largely limited to chat, reactions, donations, and rigid polls. With CrowdPlay, viewers can submit free-form ideas such as “start a blackout rescue mission” or “give the streamer a temporary rival.” AI translates multilingual messages, filters unsafe content, groups similar suggestions, and presents the creator with representative choices. Once approved, the selected idea is converted into a valid in-game event using a controlled library of mechanics, such as spawning a character, changing the environment, introducing a timed objective, or applying a gameplay constraint. Audience decisions also become persistent story elements that can influence future sessions.
